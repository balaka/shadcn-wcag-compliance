# Cheat sheet — gates on the shadcn design system (talk, 2026-10-05)

Ten minutes, then questions. Storybook running at localhost:6006; yesterday's
Claude Code chat with the refusal open in the sidebar.

## 1. What a gate is (say)

A check that runs *before* an agent's edit is saved. If the edit breaks a
rule, the file is not written and the agent gets the number back.

## 2. Why (say)

Ask an agent "is the contrast fine?" and it says "fine" without measuring.
Ask tomorrow, it says something else. A hundred components checked ten times
leave no trace. Nobody can sign off on that.

## 3. The finding — Storybook → Input › With Label → Accessibility tab

"1.26:1, needs 3:1. This is shadcn as installed. axe can't see it; this is
our rule, in the same tab. Rule written once: standard text with a date →
rule with a version → code."

## 4. The gate — yesterday's Claude Code chat, last reply, read it aloud

> "I didn't set it. The gate refused the edit: 1.35:1, rule needs 3:1.
> I won't work around it. A designer's decision doesn't change the measured
> ratio."

"I asked for a lighter border as a design decision. The file was not
written. That's the gate. Words in the chat don't open it; only the number
does. The refusal is logged."

## 5. Where a person decides — WCAG compliance › Precedents, first card

"When a rule can't settle a case, a person records a decision: what, which
text of the standard, who, why, until when. This one I approved and later
revoked; the history is kept. The two drafts below: the check said *cannot
tell*, the agent proposed *not applicable*, I decide. The agent can draft;
only a person can approve, and it can't get around that."

## 6. Close (say)

"Rules are written once and hold on every edit, agent edits included. The
check finds, the agent proposes, the person decides, and the trace stays."

---

**If asked "what's next":** more rules (focus ring, target size, colour as the
only signal); the same check on pull requests; a judge model for disputed
cases, calibrated against a golden set; `npm install` + `init` into our own
Storybook.

**If asked "can the agent bypass it":** locally it's a threshold, not a wall:
it stops mistakes and habit and leaves a trace; the wall is the PR, where
approvals come only in a person's commits.
