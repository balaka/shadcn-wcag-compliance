## What this rule is

axe-core's rule `input-image-alt`, version 4.13.0, run under our name and
number: WCAG 1.1.1, 4.1.2 (level A). The check is axe's —
https://dequeuniversity.com/rules/axe/4.13/input-image-alt — and so are its applicability and expectation; this file is
where we answer for it: which criterion it serves, which version of axe
it is, and whether it has passed its exam.

## Applicability

As axe-core 4.13.0 `input-image-alt`: elements matching `input[type="image"]`, filtered by axe's `no-explicit-name-required-matches`.

## Expectation

As axe-core 4.13.0 `input-image-alt`: Image buttons must have alternative text.

Checks (any of): `non-empty-alt`, `aria-label`, `aria-labelledby`, `non-empty-title`, `implicit-label`, `explicit-label`.
