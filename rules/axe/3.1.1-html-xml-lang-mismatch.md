axe-core's rule `html-xml-lang-mismatch`, version 4.13.0, run under our name and
number: WCAG 3.1.1 (level A). The check is axe's —
https://dequeuniversity.com/rules/axe/4.13/html-xml-lang-mismatch — and so are its applicability and expectation; this file is
where we answer for it: which criterion it serves, which version of axe
it is, and whether it has passed its exam.

## Applicability

As axe-core 4.13.0 `html-xml-lang-mismatch`: elements matching `html[lang][xml\:lang]:not(html *)`, filtered by axe's `xml-lang-mismatch-matches`.

## Expectation

As axe-core 4.13.0 `html-xml-lang-mismatch`: HTML elements with lang and xml:lang must have the same base language.
