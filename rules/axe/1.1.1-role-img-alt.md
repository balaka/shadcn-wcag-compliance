## What this rule is

axe-core's rule `role-img-alt`, version 4.13.0, run under our name and
number: WCAG 1.1.1 (level A). The check is axe's —
https://dequeuniversity.com/rules/axe/4.13/role-img-alt — and so are its applicability and expectation; this file is
where we answer for it: which criterion it serves, which version of axe
it is, and whether it has passed its exam.

## Applicability

As axe-core 4.13.0 `role-img-alt`: elements matching `:is([role='img'], [role='image']):not(img, area, input, object)`, filtered by axe's `html-namespace-matches`.

## Expectation

As axe-core 4.13.0 `role-img-alt`: [role="img"] and [role="image"] elements must have alternative text.

Checks (any of): `aria-label`, `aria-labelledby`, `non-empty-title`.
