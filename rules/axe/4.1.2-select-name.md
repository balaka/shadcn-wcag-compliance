## Applicability

As axe-core 4.13.0 `select-name`: elements matching `select`.

## Expectation

As axe-core 4.13.0 `select-name`: Select element must have an accessible name.

Checks (any of): `implicit-label`, `explicit-label`, `aria-label`, `aria-labelledby`, `non-empty-title`, `presentational-role`.
Checks (all of): —.
Checks (none of): `hidden-explicit-label`.
