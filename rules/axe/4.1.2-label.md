## What this rule is

axe-core's rule `label`, version 4.13.0, run under our name and
number: WCAG 4.1.2 (level A). The check is axe's —
https://dequeuniversity.com/rules/axe/4.13/label — and so are its applicability and expectation; this file is
where we answer for it: which criterion it serves, which version of axe

## Applicability

As axe-core 4.13.0 `label`: elements matching `input, textarea`, filtered by axe's `label-matches`.

## Expectation

As axe-core 4.13.0 `label`: Form elements must have labels.

Checks (any of): `implicit-label`, `explicit-label`, `aria-label`, `aria-labelledby`, `non-empty-title`, `non-empty-placeholder`, `presentational-role`.
Checks (all of): —.
Checks (none of): `hidden-explicit-label`.
