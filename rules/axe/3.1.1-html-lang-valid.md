## What this rule is

axe-core's rule `html-lang-valid`, version 4.13.0, run under our name and
number: WCAG 3.1.1 (level A). The check is axe's —
https://dequeuniversity.com/rules/axe/4.13/html-lang-valid — and so are its applicability and expectation; this file is
where we answer for it: which criterion it serves, which version of axe
it is, and whether it has passed its exam.

## Applicability

As axe-core 4.13.0 `html-lang-valid`: elements matching `html[lang]:not([lang=""]):not(html *), html[xml\:lang]:not([xml\:lang=""]):not(html *)`.

## Expectation

As axe-core 4.13.0 `html-lang-valid`: <html> element must have a valid value for the lang attribute.
