## What this rule is

axe-core's rule `input-button-name`, version 4.13.0, run under our name and
number: WCAG 4.1.2 (level A). The check is axe's —
https://dequeuniversity.com/rules/axe/4.13/input-button-name — and so are its applicability and expectation; this file is
where we answer for it: which criterion it serves, which version of axe
it is, and whether it has passed its exam.

## Applicability

As axe-core 4.13.0 `input-button-name`: elements matching `input[type="button"], input[type="submit"], input[type="reset"]`, filtered by axe's `no-explicit-name-required-matches`.

## Expectation

As axe-core 4.13.0 `input-button-name`: Input buttons must have discernible text.

Checks (any of): `non-empty-if-present`, `non-empty-value`, `aria-label`, `aria-labelledby`, `non-empty-title`, `implicit-label`, `explicit-label`, `presentational-role`.
Checks (all of): —.
Checks (none of): —.
