## What this rule is

axe-core's rule `aria-hidden-focus`, version 4.13.0, run under our name and
number: WCAG 4.1.2 (level A). The check is axe's —
https://dequeuniversity.com/rules/axe/4.13/aria-hidden-focus — and so are its applicability and expectation; this file is
where we answer for it: which criterion it serves, which version of axe
it is, and whether it has passed its exam.

## Applicability

As axe-core 4.13.0 `aria-hidden-focus`: elements matching `[aria-hidden="true"]`, filtered by axe's `aria-hidden-focus-matches`.

## Expectation

As axe-core 4.13.0 `aria-hidden-focus`: ARIA hidden element must not be focusable or contain focusable elements.

Checks (any of): —.
Checks (all of): `focusable-modal-open`, `focusable-disabled`, `focusable-not-tabbable`.
Checks (none of): —.
