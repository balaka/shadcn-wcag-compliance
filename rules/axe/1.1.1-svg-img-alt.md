## What this rule is

axe-core's rule `svg-img-alt`, version 4.13.0, run under our name and
number: WCAG 1.1.1 (level A). The check is axe's —
https://dequeuniversity.com/rules/axe/4.13/svg-img-alt — and so are its applicability and expectation; this file is
where we answer for it: which criterion it serves, which version of axe
it is, and whether it has passed its exam.

## Applicability

As axe-core 4.13.0 `svg-img-alt`: elements matching `:is([role='img'], [role='image']), [role='graphics-symbol'], svg[role='graphics-document']`, filtered by axe's `svg-namespace-matches`.

## Expectation

As axe-core 4.13.0 `svg-img-alt`: <svg> elements with an img or image role must have alternative text.

Checks (any of): `svg-non-empty-title`, `aria-label`, `aria-labelledby`, `non-empty-title`.
