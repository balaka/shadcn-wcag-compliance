## What this rule is

axe-core's rule `aria-toggle-field-name`, version 4.13.0, run under our name and
number: WCAG 4.1.2 (level A). The check is axe's —
https://dequeuniversity.com/rules/axe/4.13/aria-toggle-field-name — and so are its applicability and expectation; this file is
where we answer for it: which criterion it serves, which version of axe
it is, and whether it has passed its exam.

## Applicability

As axe-core 4.13.0 `aria-toggle-field-name`: elements matching `[role="checkbox"], [role="menuitemcheckbox"], [role="menuitemradio"], [role="radio"], [role="switch"], [role="option"]`, filtered by axe's `no-naming-method-matches`.

## Expectation

As axe-core 4.13.0 `aria-toggle-field-name`: ARIA toggle fields must have an accessible name.

Checks (any of): `has-visible-text`, `aria-label`, `aria-labelledby`, `non-empty-title`.
Checks (all of): —.
Checks (none of): `no-implicit-explicit-label`.
