axe-core's rule `object-alt`, version 4.13.0, run under our name and
number: WCAG 1.1.1 (level A). The check is axe's —
https://dequeuniversity.com/rules/axe/4.13/object-alt — and so are its applicability and expectation; this file is
where we answer for it: which criterion it serves, which version of axe

## Applicability

As axe-core 4.13.0 `object-alt`: elements matching `object[data]`, filtered by axe's `object-is-loaded-matches`.

## Expectation

As axe-core 4.13.0 `object-alt`: <object> elements must have alternative text.

Checks (any of): `aria-label`, `aria-labelledby`, `non-empty-title`, `presentational-role`.
